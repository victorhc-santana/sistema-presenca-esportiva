# sistema-presenca-esportiva
Nome do Projeto: Sistema de Presença Esportiva.

Nome dos Integrantes: Victor Hugo Campos Santana, Bruno Tresoldi.

Tema escolhido: Sistema feito para uso em um centro esportivo dedicado a levar saúde e lazer para a população.

Descrição do problema resolvido: Acompanhamento do progesso e comunicação entre a secretaria e alunos.

Lista de entidades implementadas: Turma, Matricula, Presença e Aluno.

Instruções para execução: - Cadastrar um aluno inserindo os dados;
                          - Cadastrar uma turma inserindo os dados da turma;
                          - Cadastrar uma matricula dos alunos nas turmas desejadas;
                          - Registrar presença preenchendo o nome da turma, pesquisar, marcar presença na caixinha e salvar;

Divisão e responsabilidades por integrantes: Victor foi responsável por criar os CRUDS Aluno e Presença implementando todos os requisitos do trabalho para cada CRUD;           
Bruno foi reponsável por criar os CRUDS Turma e Matricula implementando todos os requisitos do trabalho para cada CRUD;
